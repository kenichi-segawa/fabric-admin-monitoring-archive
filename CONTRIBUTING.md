# Contributing

1. Fork the repository.
2. Create a feature branch.
3. Do not commit tenant IDs, workspace IDs, credentials, user data, outputs, or screenshots.
4. Run:

   ```bash
   python scripts/validate_solution.py
   powerbi-report-author validate "solution/Admin Monitoring Governance & Adoption.Report"
   ```

5. Open a pull request with a clear description and validation results.
